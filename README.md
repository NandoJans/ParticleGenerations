# ParticleGenerations

An incremental game about particle generation and cosmic evolution.

## Development Tools

### Dev Phase Selector

The Dev Phase Selector allows developers to quickly jump to different phases of the game for testing purposes. See [DEV_PHASE_SELECTOR.md](DEV_PHASE_SELECTOR.md) for detailed documentation.

Access the tool at: `#/dev/phase`

### Balance Tool

The Balance Tool helps analyze game progression and balance. Access it at: `#/dev/balance`
